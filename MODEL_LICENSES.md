# Model weight provenance

Every model weight we mirror is recorded here: origin, license, and the
verification that it permits commercial use and redistribution (the policy
in docs/DEPENDENCIES.md), or the recorded exception when it doesn't. Weights are never committed to this repo. A weight not listed here
does not ship.

Status values: **planned** (selected, license verified from the original
source, not yet mirrored) · **mirrored** (live on our mirror) · **excluded**
(evaluated and rejected — kept here so it isn't re-litigated).

The app downloads exactly these files (crates/karaoke-core/src/models/manifest.json — path, size and
sha256 per file, in three packs: core, transcription, high_quality). Keep the two in step.

The mirror is `https://models.baritoad.com/v1/` — our Cloudflare R2 bucket `baritoad-models` on its
custom domain, live 2026-10-02. Files are immutable under `v1/` (served with
`Cache-Control: public, max-age=31536000, immutable`); a changed file gets a new path prefix and a
manifest update, never an overwrite. (One exception, for the license texts
beside the models, not the models: on 2026-10-05 the two Demucs
`.LICENSE.txt` files, which wrongly called the weights MIT, were corrected in
place and now carry `Cache-Control: public, max-age=86400`.) Checked after upload: `rclone check` (13 files, 0 differences),
every file public with the right size, a Range request answered 206, and a real first-run download
by the app into an empty folder — all 9 manifest files matched their sha256.

Verification rule: license is confirmed from the *original* publisher's
repo/model card for the exact checkpoint mirrored — never from a re-uploader's
claim. Record the URL and date in the Verified column when a row moves to
"mirrored". A model card's license tag isn't enough on its own: also check
the publisher's README and issue tracker for statements about the weights
(the Demucs cards said `mit` while the author had said in the issues, more
than once, that the weights aren't MIT — and the tag was later removed).
