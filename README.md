# Karaoke App (working title)

The karaoke machine for any song — local-first, no subscription, no catalog.
You bring the music: drop in a song you own, get AI vocal removal, word-synced
scrolling lyrics, and a full-screen player.

**Status:** pre-alpha. Currently in Phase 0 (feasibility spikes) — see
[PLAN.md](PLAN.md) for the full plan and [spikes/](spikes/README.md) for what's
being de-risked.

**License:** source-available (Aseprite-style; final EULA pending — PLAN.md §8).
The code is public to read, build, and use personally; official binaries will
be sold, and binary redistribution/resale is not permitted. This is *not* OSI
open source, and we won't call it that.
